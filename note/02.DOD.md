## SOA / AOS

#### AOS: Array Of Strcuts (单个) 编辑状态合适

#### SOA: Structre Of Array (批量) 运行状态下适合

## ECS

Entry Components System 负责系统架构。常见的高性能核心使用的是
ESC + SOA （布局）。这样子能更合理的理由cpu缓存机制。

## contiguous memory

连续内存最大的优势就是可以让cpu更好的利用cache line 和 prefetch 机制。
减少cache miss。因为现在cpu的计算速度非常快。大部分时间在读取内存阻塞。

## chunk

将一大块内存分区处理。可以更好的利用现代cpu的能力。
如果直接对一大块内存处理。内存可能直接爆炸。
比如做的分区导出图片就是一个很好的列子

## sparse set

使用双 array 来解决单个数组的 增删改查+遍历。
从而最大利用 cpu 的 cache 机制。

## arena allocator

提前分配一块大内存，而不是自己在循环体里面 for -> new
只不过。在删除时。只能整体删除。而不是单个删除
